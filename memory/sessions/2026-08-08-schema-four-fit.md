# 開場四張同屏＋連線風格待補

## 摘要

四張紙本要同時出現在一屏；欄位字都要看得見（可很小）。連線先用精簡圖例；使用者稍後會上傳喜歡的連線風格再換成那套。

## 重點

- 2×2 紙本格＋自動縮放進可視區
- 每張顯示全部欄位標籤（字小、空白格極薄）
- 連線：暫用底部 `A→B 1:n` 圖例，**非正式定案**

## 決定／偏好

- 同屏優先於單張舒適閱讀
- 連線視覺：等使用者開電腦上傳參考樣式

## 待續

- [ ] 使用者上傳連線風格後替換 `schema-key`
