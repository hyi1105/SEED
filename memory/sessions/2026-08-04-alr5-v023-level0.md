# ALR5 v0.2.3：required_from_level=0

## 摘要

使用者補定：`required_from_level = 0` 代表申請人填寫階段就必填，後續各關也必填。

## 重點

- ＝0 → Submit 擋（空／0）；後續亦必填
- ≥1 → 該關 Approve 前擋，不擋申請人 Submit
- SAVE 一律不擋

## 待續

仍待決見標準 open_questions／規格 §10b。
