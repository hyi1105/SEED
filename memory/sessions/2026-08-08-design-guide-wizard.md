# 導引功能：從聊需求到可用系統

## 摘要

新增「導引」模式：用催收系統當例子，示範使用者講需求 → 顧問補欄位 → 問申請人／催收人權限 → 收成 JSON → 打開可播放系統。並新增第二套系統包「催收單」。

## 重點

- 頂部第四個模式：**導引**
- 六階段教學（聽需求／補催收欄位／申請人權限／催收人權限／成檔／可用系統）
- CTA「打開催收系統導覽」會載入 `systems/collection.json`
- 面板可切換系統：離職單／催收單

## 決定／偏好

- 導引是教學網站核心路徑之一（需求對話 → 欄位管理 → 每欄做什麼）
- 示範用催收（一／二／三催＋結案），不是只教離職單
