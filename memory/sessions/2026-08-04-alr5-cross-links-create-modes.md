# 需求記憶：跨單關聯鏈＋兩種開單模式

## 摘要

使用者補充：B 要等 A 完成（單號＋狀態）才能往下；C 可等 B，甚至也要 A。儀器校正類似（A 儀器、B 校正報告→回寫 A 下次校正日）。開單分「需要時建立」與「預先建立／搶位」。尚未想好怎麼串，標準先給骨架建議。

## 重點

1. **跨單鏈**：prerequisites＋links＋effects_on（完成回寫）
2. **認證感**：建議主檔＋事件（A 主檔、B 事件回寫 A），不是登入認證
3. **on_demand**：需要時建立
4. **preallocated**：預建名額／庫位；行事曆看 open item 搶；實物到齊再往下

## 建議模型（給使用者確認）

- 校正：A 存「下次校正日／合格」；B 每次校正；C 查 A 即可
- 純專案鏈：也可只用 prerequisites 串 A→B→C
