# ALR5：捨棄棋盤，改自由流程說明圖

## 摘要

不要棋盤。希望像跟外面廠商談專案時那張流程圖：非技術背景也能看懂。圓＝人、方＝欄位／文件、箭頭＝動作／寄信。

## 重點

- `mail_board.schema = 3`：`nodes[]` + `edges[]`
- 加人／欄位：點材料 → 點圖空白處
- 加箭頭：點動作／寄信 → 起點 → 終點
- 圓／方可拖；寄信標籤點兩次編信件

## 決定／偏好

- 捨棄棋盤網格
- 對外可讀優先於技術儀表板感
