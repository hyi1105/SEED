# 學習／導覽偏好：漸進拼圖（四合院式）

## 摘要

定下導覽節奏：**先空舞台，一塊塊長名稱**——參考四合院 3D 相簿的節奏（模型漸長＋巨大標籤綁空間＋字幕講用途），**不是**做四合院主題。與「空白起源」同一條線：答對「下一塊該長什麼／誰用／為什麼」才長出；模型走完再接真實畫面驗證。

## 重點

### 參考節奏（非主題）

- 連結：https://photos.app.goo.gl/ARjDdXCuyPNYhSiP8
- 文字記憶：3D 模型一塊塊長出；巨大標籤綁在空間位置；字幕講這塊用途
- Agent 本場無法登入 Google Photos 看原圖；以使用者描述為準

### 要做成

1. 先空舞台，不要一次攤開全部名稱
2. 分區：申請端／處理中段／結案／權限／產出物
3. 每一步只長一小撮「名稱＋一句用途」
4. 先問「下一塊該長什麼／誰用／為什麼需要」，答對才長出
5. 名稱永遠掛在所屬區塊上
6. 模型走完後，再連到真實畫面／流程驗證

### 不要做成

- 長篇一次講完
- 只有測驗沒結構
- 一開始就丟完整 ER／選單

### 完成定義

新手能指著拼圖說出：有哪些名稱、各在哪一區、誰能動、用來完成什麼需求。

## 決定／偏好

- 導覽＝**漸進拼圖**，不是簡報念稿，也不是純考題
- 分區固定五類（申請端／處理中段／結案／權限／產出物）；名稱長在區上
- 「答對才長出」＝學習閘門；錯了重問／提示，不一次翻牌
- 拼圖完成 → 才進真實畫面／流程驗證（與既有演示／地圖銜接）
