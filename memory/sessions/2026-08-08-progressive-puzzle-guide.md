# 學習／導覽偏好：漸進拼圖（四合院式）

## 摘要

定下舞台節奏：**先空舞台，一塊塊長名稱**——參考四合院 3D 相簿的節奏（模型漸長＋巨大標籤綁空間＋字幕講用途），**不是**做四合院主題。  
**推進方式已改訂**（同日 02:41）：不是問答閘門，而是 **視覺小說式 show**——點下一步推進；詳見 [vn-show-guide](./2026-08-08-vn-show-guide.md)。

## 重點

### 參考節奏（非主題）

- 連結：https://photos.app.goo.gl/ARjDdXCuyPNYhSiP8
- 文字記憶：3D 模型一塊塊長出；巨大標籤綁在空間位置；字幕講這塊用途
- Agent 本場無法登入 Google Photos 看原圖；以使用者描述為準

### 要做成（舞台／結構）

1. 先空舞台，不要一次攤開全部名稱
2. 分區：申請端／處理中段／結案／權限／產出物
3. 每一步只長一小撮「名稱＋一句用途」
4. ~~答對才長出~~ → **改**：點「下一步」推進劇情，台詞後舞台長出；關鍵節點才出現選項（Choices）
5. 名稱永遠掛在所屬區塊上
6. 模型走完後，再連到真實畫面／流程驗證

### 不要做成

- 長篇一次講完
- 只有測驗沒結構／把學習做成答題過關
- 一開始就丟完整 ER／選單

### 完成定義

新手能指著拼圖說出：有哪些名稱、各在哪一區、誰能動、用來完成什麼需求。

## 決定／偏好

- 舞台結構＝**漸進拼圖**（四合院式節奏）
- 演出形式＝**視覺小說 show**（下一步為主、選項為輔）— 見 VN 場次
- 分區固定五類；名稱長在區上
- 拼圖完成 → 才進真實畫面／流程驗證
