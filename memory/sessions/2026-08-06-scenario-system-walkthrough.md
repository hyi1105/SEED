# 構想：情境式快速認識陌生系統

## 摘要

提出「資料血緣圖 + 角色切換 + 情境選擇 + 逐步欄位高亮」作為快速上手陌生系統的方式；以離職單（人事 API／人員主檔／離職單主檔）為例。Agent 評價為方向正確，並建議強化動作類型、跨角色接龍、欄位覆蓋熱圖、風險註記，以及平台無關的 JSON 模型。

## 重點

- 現有：靜態資料血緣（表、欄位、sync／lookup）
- 新增：角色（員工／主管／HR）× 情境（想離職、育嬰留停…）× 操作步驟高亮
- 價值：看出欄位為何存在、多餘／舊欄位、邏輯與風險

## 決定／偏好

- 採用「角色／情境／步驟」三層分離
- 跨平台用 JSON 描述系統，畫面只播放
- 詳見主題筆記建議清單
