# 構想：地圖式系統儀表板＋AI 產 JSON

## 摘要

在離職單 MVP 基礎上調整呈現：改成**可拖拉／縮放的地圖式儀表板**（手機優先），讓系統「看起來是活的」、可從任何角度認識。同時把整套做成網站：執行期吃 **JSON**，用 **JSON Schema + SKILL.md** 當「自創語言」契約，讓 AI 依指令產出可播放的系統包。

## 重點

### 呈現（地圖儀表板）

- 表／欄位是地圖上的物件：可拖、可縮放、可漫遊
- 手機優先：主畫面是地圖；角色／情境／步驟收在可收合面板
- 版面記憶（localStorage；之後可寫回 layout.json）
- 同一份資料，多種視角（血緣高亮、角色旅程、覆蓋熱圖）

### 資料與「語言」

| 層 | 建議 | 角色 |
|---|---|---|
| 執行期 | **JSON**（`system.json`） | 網站只認這個 |
| 契約 | **JSON Schema** | 驗證、防 AI 胡寫 |
| 寫作說明 | **SKILL.md** | 教 AI／人怎麼填 |
| （可選）人類草稿 | YAML | 之後可編譯成 JSON |

**結論：先不要真的發明新語法。** JSON + Schema + Skill 已經是「自創語言」：有詞彙（entities／roles／scenarios／steps）、有文法（schema）、有寫作規範（skill）。等痛點出現再加 YAML 或 DSL。

## 決定／偏好

- 呈現朝地圖儀表板走，手機可拖可縮
- 資料格式維持 JSON；Schema + Skill 當 AI 產物契約
- 網站＝播放器；系統包＝可攜 JSON（可多系統切換）
