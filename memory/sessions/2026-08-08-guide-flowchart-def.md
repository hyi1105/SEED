# 導引圖按定義重畫：圖形＝動作種類

## 摘要

使用者指出先前泳道只是「影子標籤」、看不懂。已改成**標準導引／流程圖定義**：每種圖形固定意義、箭頭表示流程、上方常駐圖例；拿掉無意義佔位。

## 圖形定義（定案）

| 圖形 | kind | 意義 |
|---|---|---|
| 黃橢圓 | `start`／`end` | 開始／結束 |
| 藍矩形 | `process` | 處理（做一件事） |
| 斜平行四邊形 | `io` | 輸入／填寫 |
| 菱形 | `decision` | 判斷／分支 |
| 黑箭頭 | `from` 連線 | 流程方向（可加 edgeLabel） |

位置：上＝表單，左＝人（交叉泳道當座標，不是裝飾格）。
