# 需求記憶：AB 表單＋可設定匯出＋JSON 完全轉移

## 摘要

使用者要記住並寫進標準：AB 表單（A 表頭／B 明細）、固定格式匯出給他司／他系統、皆以設定完成；全部是可完全轉移的 JSON；他系統依 JSON 規範自動補齊缺功能／缺欄。JSON 必須寫好機讀。

## 重點

1. **AB form**：A＝表頭，B＝detail／lines；使用者設定完成。
2. **固定匯出**：指定格式給其他公司／系統；設定驅動，非改 code。
3. **完全轉移 JSON**：form／item／匯出設定／權限／流程皆可序列化搬遷。
4. **自動補齊**：接收端依 ALR5 規範補缺欄／缺功能預設；未知欄保留。
5. **standard 要寫好**：機讀、有預設、有 checklist。

## 決定／偏好

- 優先「設定讓使用者自己完成」，不靠改程式。
- 與 MVC：M＝這份可轉移 JSON；C＝功能符合；V＝自訂。
