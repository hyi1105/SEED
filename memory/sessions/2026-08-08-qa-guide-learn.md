# 導引改問答學習（先想再選再揭曉）

## 摘要

使用者分享 Facebook Reel 學習風格連結，希望用「問答」方式學系統設計。導引模式改成：故事鉤子 → 三選一 → 回饋 → 再揭曉欄位／權限／對話；答完才能下一關。

## 重點

- 參考：`https://www.facebook.com/share/r/1BgPFArrv1/?mibextid=wwXIfr`（環境抓不到影片內容，依「問答學習」意圖實作）
- `guide.json`：`style: "qa"`，每階段含 `story` + `quiz`（ask／choices／explain）
- 播放器：選錯也會顯示說明與正解標示；側欄關卡線性解鎖
- 路徑不變：聽需求 → 補催收欄位 → 申請人／催收人權限 → 成檔 → 打開催收導覽

## 決定／偏好

- 偏好**互動問答**勝過單向腳本對話
- 答完才揭曉白板／權限，避免先偷看答案
