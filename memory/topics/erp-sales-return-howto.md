# ERP：從營業出貨單打退貨單

## 一句話

先看「出庫確認」——未確認通常不能（也不該）打退貨；確認後用「相關」產生銷退，或新增後改成退貨單別再引用原出貨。

## 畫面來源（2026-08-07）

- 單據：**營業出貨單**（單別 `SN1`）
- 出貨單號：`2608050006`（日期 2026/8/5）
- 客戶：璟郁（C1）
- 來源訂單：`SO12607230002`
- 可否引用：可以引用
- **出庫確認：未出庫確認**（畫面重點）
- 工具列可見：新增、複製新增、**14個相關**、儲存修改、刪除這筆、單據列印

## 先判斷：你要的是「退貨」還是「取消出貨」？

| 實際狀況 | 該做什麼 | 不該做什麼 |
|---|---|---|
| 貨還在倉庫／還沒真正出庫 | 刪除或作廢這張出貨單 | 不要打退貨單 |
| 貨已出給客戶，客戶要退回來 | 先出庫確認 → 再開銷退／退貨單 | 不要只改數量卻不走退貨單 |

這張單目前是「未出庫確認」，若人貨都還沒出，優先走**刪除／作廢**，不是退貨。

## 建議操作（已出貨、要退）

### 步驟 1：先完成出庫確認

1. 開著這張出貨單 `2608050006`。
2. 找到「出庫確認」功能（工具列／功能鈕，名稱可能是「出庫確認」或類似）。
3. 執行後，欄位 **28. 出庫確認** 應從「未出庫確認」變成已確認。
4. 未確認時，相關開單或引用常會被擋；畫面把這欄框起來就是在提醒這點。

### 步驟 2（優先）：用「14個相關」產生退貨

1. 點工具列 **「14個相關」**。
2. 在清單找：**銷貨退回單／銷退單／產生退貨**（名稱依系統設定）。
3. 選要退的明細與數量（不可超過已出可退量）。
4. 儲存；若系統有「入庫確認／驗收」，再做入庫。

優點：客戶、品號、來源出貨／訂單會自動帶入，較不易開錯。

### 步驟 3（備援）：新增後改單別再引用

1. 點 **「新增」**（不要用「複製新增」複製成另一張 SN1 出貨）。
2. 把 **2. 出貨單別** 從 `SN1, 營業出貨單` 改成退貨／銷退單別（例如銷貨退回單；實際代碼看下拉）。
3. 用引用／來源單號帶入原出貨 `2608050006` 或訂單 `SO12607230002`。
4. 填退貨數量 → **儲存修改** →（若有）入庫確認。

## 關鍵欄位對照

| 欄位 | 這張單的值 | 退貨時要注意 |
|---|---|---|
| 2. 出貨單別 | SN1 營業出貨單 | 退貨要用銷退／退貨單別，不是 SN1 |
| 13. 訂單單號 | SO12607230002 | 可當引用來源 |
| 27. 可否引用 | 可以引用 | 理論上允許被下游引用 |
| 28. 出庫確認 | 未出庫確認 | **先確認，再退貨** |

## 常見卡住原因

1. **未出庫確認** → 先確認出庫（或改走刪除出貨）。
2. 點了相關卻沒有「銷退」→ 權限不足，或公司未開該關聯；改走新增＋改單別，或找管理員。
3. 可退數量為 0 → 已全退、或尚未確認出庫導致無可退量。
4. 用「複製新增」卻忘了改單別 → 會再開一張出貨，不是退貨。
