# 學習陌生系統：由大到小（可貼給其他 Agent）

> 用途：使用者已在別處畫好系統／程式；要另一個 Agent（如 iAgent）用「跟 SEED Show 同一套節奏」教他讀懂，而不是一次攤開。

## 可貼提示詞（繁中）

把下面整段貼給 Agent；必要時把「我的系統」改成你的名稱或再附上截圖／檔案。

````text
【任務】教我學會「我已經畫好的這套系統」。我主要是在學習，不是要你重做一版新產品。

【節奏：由大到小】（務必遵守）
1. 先不要出現一堆空白欄位或沒意義的空格。
2. 第一屏先給「藍圖／總覽」：這套系統有幾張表單（或幾個大區塊）、彼此怎麼連（誰連誰、一對多／圖狀關係）。
3. 總覽要盡量同一畫面看完（字可以很小，但大結構要齊）。
4. 外型前後要一致：總覽裡的每一張，也要長得像後面真正填寫的那張紙／表單，不要前面按鈕、後面表單兩種皮膚。
5. 大圖講清楚之後，再進「其中一張」：才長出欄位、一步一步填／講為什麼需要這個欄位。
6. 推進方式像教學 Show：上一步／下一步；關鍵分歧才給選項。不要一開始考試、不要長篇一次講完。

【每一層要講清楚】
- 大：有哪些表單／區塊、誰連誰、完成一件事要經過哪幾張
- 中：進到某一張時，這張紙上有哪些欄位名稱（字要看得見）
- 小：某一個欄位為什麼存在、誰填、跟上一張／下一張怎麼連

【完成定義】
我能指著畫面說：
- 這系統有幾張大表／區塊
- 它們怎麼連
- 某一張裡有哪些重要欄位、各用來完成什麼

【輸出】
請直接用這個節奏帶我走一遍（可用對話＋簡單圖示／紙本示意）。先從藍圖開始，等我說「下一步」再往下一層。
````

## 一句話版（更短）

````text
教我學這套已畫好的系統：先藍圖（幾張表、誰連誰，同一屏看完），外型前後一致；不要先丟空白欄位。再進單張講欄位。用上一步／下一步，由大到小。
````

## 與 SEED 對照

| 層 | SEED 做法 |
|---|---|
| 大 | `showSchema`：表單關係圖 |
| 中／小 | 進單一 `form`，逐步 `reveal`／填值 |
| 推進 | Show：下一步，不是答題閘門 |
