# 故事式泳道：讓被迫學習的人也想看下去

## 一句話

不要先塞欄位。用**像偽代碼的圖**＋**分區位置**講「現在發生什麼」；節奏像短片／視覺小說，照顧情緒價值。

## 問題

- 現在就算有紙本／關係圖，仍難**立刻**懂「這系統在幹嘛」
- 被迫學 → 需要**想繼續看**的感覺（故事、畫面整體感）
- 轉場細節可先放下；**整體敘事與畫面**比較重要

## 靈感來源

1. **流程圖（Visio／偽代碼圖）**  
   - 橢圓：使用者申請／一個動作  
   - 橢圓或菱形：遇到狀況 → 左／右分支  
   - 圖在講「流程邏輯」，不是 ER
2. **四合院短片節奏**（相簿參考）  
   - 一塊塊長出、標籤綁空間、旁白講用途  
   - 想讓人一直看下去
3. **位置＝意義**  
   - 例如由左到右四條「線／欄」（四張表單）  
   - 現在做第一張表 → 節點畫在第一欄  
   - 第二個人／第二張表 → 畫在「人 × 表」交會處  

（以上是例子；軸可以是：表單 × 角色、或 階段 × 表單。）

## 建議畫面（學習主舞台）

```
        表單 A        表單 B        表單 C        表單 D
角色／  ┃            ┃            ┃            ┃
旁白    ┃   (橢圓)   ┃            ┃            ┃
        ┃     ↓      ┃            ┃            ┃
企劃    ┃   (橢圓)───╋──→(分支)   ┃            ┃
        ┃            ┃     ↙  ↘   ┃            ┃
倉庫    ┃            ┃  (橢圓)    ┃  (橢圓)    ┃
```

- **橫軸**：大區塊（四張表／四條線）— 對應「藍圖」
- **縱軸或流動**：誰在做事、故事進度
- **節點形狀**：動作＝橢圓；抉擇＝可分支的橢圓／菱形
- **下方**：一句旁白／對話（像 Show），按「下一步」節點長出來或亮起來
- **欄位細節**：點進某個橢圓才展開（小），預設不佔情緒主畫面

## 情緒／節奏規則

| 要 | 不要 |
|---|---|
| 像在追故事：每步只發生一件事 | 一開場表格＋空白欄位 |
| 整體畫面有「舞台感」 | 只有文字說明 |
| 分支有戲劇感（選左／右） | 一開始考你 |
| 看完能講「剛剛發生什麼」 | 看完只記得按鈕在哪 |

## 與現有 SEED 的關係

| 現有 | 往這裡靠 |
|---|---|
| `showSchema` 紙本四張 | 升級／並行為**泳道舞台**（位置有意義） |
| Show 對話下一步 | 保留當旁白軌道 |
| 真實表單欄位 | 變成「點節點才打開」的細節層 |

## 實作切片（建議順序）

1. **故事泳道 MVP**：四欄＋橢圓節點＋旁白下一步（可先假資料料號 A→B→C→D）
2. 抉擇節點（左／右）接既有 `choices`
3. 點橢圓才開該表單欄位（小）
4. 再談精緻連線風格／轉場（使用者說可先不管）
