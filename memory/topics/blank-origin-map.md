# 空白起源地圖：從空白理解整套系統

## 一句話

把丟進來的任何系統（連結、檔、程式、整套、AI 抓的）變成「從空白長出來」的教學：每個空白為什麼存在、代表什麼、流程怎麼跑；最後列出幾張表／每表空白，並可拖空白看關聯（起源地圖）。

## 核心隱喻：空白

- **空白**＝畫面／表單上的欄位（姓名、日期、狀態、意見…），以及讓流程轉彎的按鈕（退回、撤回）
- 人看不懂系統時，先別講資料庫；先問：**這個空白是因為誰、為了什麼事才出現的？**
- 從「一片空白」聽到完整需求，空白一個個長出來；跑完流程後，所有空白都在最後一張圖上

## 學習路徑（產品要給的體驗）

1. **丟進來** — 連結／檔案／程式碼／整系統／AI 擷取（先 Web）
2. **聽／還原** — 用對話或腳本還原「需求一句 → 空白一組」
3. **起源旁白** — 每個空白掛一句：因為你說「…」，所以需要「…」
4. **VN show＋漸進拼圖** — 像視覺小說：點下一步讀台詞；舞台一塊塊長名稱（見下節）
5. **跑流程** — 申請 → 一簽 → 二簽 → 不同意退回改資料… 當劇情演完
6. **收斂清單** — 這個系統有幾張表？每張表有哪些空白？
7. **起源地圖** — 拖空白、看連線；結束停在最後完整圖
8. **真實驗證** — 模型／拼圖走完，再連真實畫面或流程演示

## 導覽節奏：漸進拼圖舞台 ＋ 視覺小說演出

> 舞台節奏參考四合院相簿（非主題）：https://photos.app.goo.gl/ARjDdXCuyPNYhSiP8  
> 演出形式＝VN show（同日改定；詳見 [sessions/2026-08-08-vn-show-guide.md](../sessions/2026-08-08-vn-show-guide.md)）

### 舞台要

| # | 規則 |
|---|---|
| 1 | **先空舞台**，不要一次攤開全部名稱 |
| 2 | **分區**：申請端／處理中段／結案／權限／產出物 |
| 3 | 每步只長一小撮「**名稱＋一句用途**」 |
| 4 | **點下一步推進**（台詞後舞台長出）；關鍵節點才 **選項（Choices）** 分歧 |
| 5 | 名稱**永遠掛在所屬區塊上** |
| 6 | 模型走完後，再連到**真實畫面／流程驗證** |

### 演出要（VN）

- 靜態／微動態背景＋角色立繪；下方**對話框**推進
- 使用者主要閱讀；像一場 show，不是考試
- 選項影響走向／結局（例：主管不同意 → 退回改單 vs 其他分支）
- 參考感：《Fate/stay night》《Steins;Gate》《Clannad》

### 不要

- 長篇一次講完
- **答題過關／只有測驗沒結構**（「答對才長出」已作廢）
- 一開始就丟完整 ER／選單

### 完成定義

新手能指著拼圖說出：有哪些名稱、各在哪一區、誰能動、用來完成什麼需求。——學會靠看 show，不是靠答題。

### 與「空白起源」怎麼疊

- 空白／按鈕＝拼圖上會長出來的「名稱」
- 起源旁白＝對話框台詞（「因為需要主管簽，所以長出…」）
- 五分區＝名稱釘死的空間
- 流程分歧＝VN 選項 → 不同結局／不同長出順序

## 請假故事線（示範腳本）

用來驗證「聽需求長空白」，可做成第三套系統包（請假），與離職／催收並列：

```
使用者：我要請假系統 → 姓名、電話、最後一天
系統：申請區出現三個空白（申請人填）

使用者：主管要簽
系統：第一簽核區：簽核人姓名、日期、狀態、意見

使用者：HR 要處理
系統：第二簽核區：同上四個空白

使用者：主管不同意可以撤回
系統：出現「退回／撤回」按鈕；一簽不通過 → 退回 → 可改資料再送
```

結束時應能回答：

- 表有幾張（例如：請假主檔、簽核歷程…；以實際還原為準）
- 每張表的空白清單與起源句
- 流程怎麼走、按鈕在什麼條件出現

## 資料原則

- 仍走 **Walkthrough JSON**（Schema + Skill）；畫面多一種 `render: vn`（或同等）
- 建議腳本節點長這樣（概念，先不必改 Schema）：
  - `speaker`／`line`：對話框
  - `reveal`：本步長出的名稱（釘在哪一 `zone`）
  - `choice[]`：可選；選了跳哪條線／哪個結局
  - `origin`／`meaning`：仍可掛在名稱上當台詞素材
- 按鈕／動作也是「空白家族」：退回鍵也要有起源台詞

## 決定／偏好

- 先 Web；教學優先於一次做完所有匯入器
- 空白起源＝主軸隱喻；地圖可拖＝「寫原圖」的操作感
- 導覽＝**漸進拼圖舞台 ＋ VN show**：下一步為主、選項為輔；**不要答題過關**
- 示範優先請假主線＋至少一個選項分歧
